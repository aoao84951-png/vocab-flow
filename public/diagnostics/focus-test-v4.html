Vocab Flow 한 편집 영역 실험 · 4차

실제 앱을 변경하지 않은 독립 실험입니다. 화면에는 두 칸이 있지만 후보 모드에서는 하나의 편집 영역 안에서 커서만 이동합니다. 글자를 비우거나 포커스를 끊는 초기화는 하지 않습니다. 성공 여부는 아직 확인되지 않았습니다.

  1. 모드를 고르고 이번 회차 시작을 누릅니다.
  2. 첫 칸에 입니다를 직접 입력합니다. 공백·Enter는 누르지 않습니다.
  3. Tab 또는 둘째 칸 터치로 이동해 ㄹ 하나를 입력합니다. 정상은 ㄹ입니다.
  4. 백스페이스 한 번 후 회차 완료를 누릅니다. 글자가 다시 나타나면 더 지우지 말고 완료해 주세요.
  5. 글자 결과와 한/영 표시 깜빡임을 선택합니다.

기준 모드 1회, 후보 모드에서 터치 3회·Tab 3회를 해 주세요. 평소 속도로 입력하면 됩니다. 마지막에 기록 파일을 한 번 받아 보내 주세요.

테스트 글자와 입력 이벤트는 이 탭 메모리에만 기록하며 서버로 전송하지 않습니다. 새로고침하거나 닫기 전에 파일을 받아 주세요. 이 실험은 칸 사이 삭제 방지나 서식 기능을 구현한 완성 편집기가 아닙니다.

기록 대기



시작·완료 버튼을 누를 때가 아니라 첫 칸에서 둘째 칸으로 옮기는 순간을 기준으로 선택해 주세요. 시스템 한/영 표시는 자동으로 관찰할 수 없어 직접 확인이 필요합니다.

아래 자동 판정은 정해진 문구를 입력했을 때만 유효하며, 해결 여부를 확정하지 않습니다. 눈으로 확인한 결과와 이벤트 기록을 함께 분석합니다.
