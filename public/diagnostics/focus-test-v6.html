Vocab Flow 하단 언어 버튼 숨김 · 6차

하단의 A/한 버튼이 사라지는지 확인하는 독립 실험입니다. 두 모드 모두 성공했던 외장 키보드 직접 한글 조합 방식을 사용하며, 후보만 화면 키보드 표시를 억제합니다. 실제 앱 설정은 변경하지 않았습니다.

매직키보드 등 외장 키보드를 연결한 상태에서 테스트해 주세요. 후보에서는 화면 키보드가 나오지 않을 수 있습니다. 물리 키보드의 한/영 전환은 평소 쓰는 키로 확인합니다.

  1. 먼저 기준을 선택하고 시작합니다. 첫 칸에 입니다를 입력합니다.
  2. Tab으로 둘째 칸에 이동 → ㄹ → 백스페이스 한 번. 이전 글자가 나타나는지도 확인합니다.
  3. 둘째 칸에서 한/영 전환 → abc → 다시 한글로 전환 → 한글을 입력합니다.
  4. 아래 입력칸 밖으로 이동 버튼을 누르고, 둘째 칸을 다시 터치합니다. 하단 버튼이 나타나거나 움직이는지 봅니다.
  5. 회차 완료 후 관찰 결과를 선택합니다. 후보로 바꾸어 같은 과정을 1회 반복하고 기록 파일을 받습니다.

화면 위쪽에 잠깐 뜨는 언어 전환 알림은 정상입니다. 확인할 대상은 사진에서 표시했던 오른쪽 아래 A/한 버튼입니다. 시스템 버튼의 표시 여부는 웹페이지에서 자동으로 읽을 수 없습니다.

입력 내용과 키 이벤트는 이 탭 메모리에만 보관하며 서버에 전송하지 않습니다. 새로고침 전에 파일을 받아 주세요.

둘째 칸 — ㄹ 입력 후 백스페이스
